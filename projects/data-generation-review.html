데이터 생성 및 검수 프로세스 경험

2024.07 – 2025.02

한국어 QA(질의응답) 데이터 생성·검수 및 이미지 라벨링 작업에 참여하며, 데이터 품질을 일관되게 유지하기 위한 판단 기준을 표준화한 경험입니다.

주요 작업

  • 한국어 QA 데이터 생성 및 검수 작업 수행
  • 이미지 라벨링 판단 기준 표준화
  • 표준화된 기준 적용을 통한 데이터 품질 편차 개선

배운 점

데이터 품질은 생성 단계뿐 아니라 명확한 검수 기준과 일관된 적용에서 결정된다는 점을 직접 경험했고, 이는 이후 데이터 파이프라인을 설계할 때 신뢰성 있는 검증 절차를 포함시키는 습관으로 이어졌습니다.
